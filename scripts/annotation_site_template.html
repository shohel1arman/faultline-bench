FaultLine human check

You will see photos. For each one:

  1. Answer the question from the photo. Pick the option that is true in the photo. Choose Can't tell if the photo does not let you decide (object too small, hidden, several objects the question could mean) or if more than one option is true. You see the description only after this step.
  2. Does the description match the photo? Read the whole description. Answer No if any part of it is false for the photo.
  3. If it does not match: how obvious is the mistake? Obvious: you notice it at once. Moderate: you notice it after looking. Subtle: you need to look closely.

Left, right, above, below are as seen in the photo (the viewer's left), not the object's own left. Colours mean the main colour of the object. Work on your own and do not discuss items with the other annotator.

Keys: 1–4 options, 5 can't tell; Y / N / C for the description; 1 / 2 / 3 for how obvious; ← → to move.
